# libukvenus autogeneration

`libukvenus` is the Unikraft guest-side encoder for the Venus Vulkan wire
format. Mesa's [venus-protocol](https://gitlab.freedesktop.org/mesa/venus-protocol)
already owns the canonical generator: it walks `vk.xml` plus
`VK_MESA_venus_protocol.xml` and renders Mako templates into header-only
encoders.

Rather than fork those 3,000+ lines of Python and 30+ Mako templates into
VOGUE, libukvenus *consumes* that generator through the sibling
`../venus-protocol/` checkout. This file describes the plan; the actual
runner is `scripts/gen_libukvenus.py`.

## Layout

```
scripts/gen_libukvenus.py             # entry point (this project)
../venus-protocol/                    # upstream Mako generator + vk.xml
libs/libukvenus/generated/            # output, git-ignored
libs/libukvenus/venus_cs.c            # hand-written wrappers calling generated encoders
libs/libukvenus/include/uk/venus.h    # public API (stable)
```

## Workflow

```sh
make gen-libukvenus-plan      # JSON plan: artifacts, slices, source script
make gen-libukvenus-check     # verify ../venus-protocol checkout + mako
make gen-libukvenus           # regenerate libs/libukvenus/generated/*
```

## Slicing for image size

Only the Vulkan extensions actually needed by upstream `ggml-vulkan.cpp`
are enabled — see `WANTED_EXTENSIONS` in `scripts/gen_libukvenus.py`. The
slice is intentionally smaller than Mesa's because the unikernel image
must stay minimal.

## Upgrade procedure

1. `git -C ../venus-protocol pull` (or update to the desired Mesa SHA).
2. Re-run `make gen-libukvenus`.
3. Commit only `libs/libukvenus/generated/` plus any hand-written wrapper
   updates required for new types.
4. Re-run `make native-tests venus-check` to confirm wire-format compatibility.

## Why not vendor

- Mesa changes the Venus wire-format on minor Mesa releases.
- The encoder is autogenerated upstream; vendoring would mean re-applying
  patches on every upgrade.
- Keeping `libs/libukvenus/generated/` out of source control until needed
  ensures the project stays small for review and `make verify`.
