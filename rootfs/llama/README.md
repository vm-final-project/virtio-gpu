# llama.cpp model rootfs staging

This directory is the optional model/shader staging area for the upstream
llama.cpp Unikraft appliances. Current Kraftfiles prefer 9pfs for local smoke
runs, but initramfs-style staging may still copy the same files from here.

Expected content when staging is used:

```text
/models/<name>.gguf      model mounted at /mnt/model/model.gguf or /models/...
/shaders/<name>.spv      optional SPIR-V artifacts generated by upstream ggml-vulkan
```

Real GGUF and SPIR-V artifacts are not vendored into git. The environment matrix
(`config/llama_env_matrix.json`) records the model path, thread counts, backend
flags, and claim boundaries for every baremetal/QEMU/Unikraft row.

The rootfs must not contain a shell or unrelated utility application for the
Unikraft rows. A llama appliance boots directly into exactly one entrypoint:
CPU bench-only, CPU server-only, Vulkan bench-only, or Vulkan server-only.
Native server images do not run a `fork()`/`exec()` launcher; ELF Loader is only
a separate x86_64 discovery path for Linux-binary compatibility gaps.
